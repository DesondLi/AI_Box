# AI Box - 物联网通用微内核架构

面向物联网全场景设计的通用软件架构，支持可配置逻辑围栏、数据 IO 抽象、LLM 加速与热拔插。

## ✨ 核心特性

### 🧩 微内核插件系统
- **完整生命周期管理**：install → start → stop → uninstall 四阶段
- **依赖拓扑排序**：自动解析插件依赖，支持循环依赖检测
- **能力发现机制**：插件间松耦合能力注册与调用
- **上下文注入**：插件通过标准接口访问内核服务

### 📡 MQTT 消息总线
- **完整 MQTT 3.1.1 通配符支持**：`+` 单层匹配，`#` 多层匹配
- **发布/订阅模式**：异步消息投递
- **请求/响应模式**：服务调用支持
- **98% 测试覆盖率**

### 🧠 RAG/Memory 时序数据语义桥接器
**解决物联网海量时序数据与 LLM 之间的语义断层问题**

- **Token 压缩比 9:1**：300 个浮点数 → 30 token 的自然语言摘要
- **三级摘要策略**：
  - Level 0：规则模板生成（零延迟、零成本、无外部依赖）
  - Level 1：本地小模型量化推理（边缘友好）
  - Level 2：云端大模型生成（高质量摘要）
- **时序趋势检测**：自动识别上升/下降/稳定/波动四种趋势
- **异常标注**：支持严重等级 + 上下文偏离度计算
- **LLM 上下文构建**：自动聚合时间线 + 统计汇总

## 🏗️ 架构设计

### 分层架构
```
┌─────────────────────────────────────────────┐
│ Layer 6: Agent 应用层       LangGraph + Skill│
├─────────────────────────────────────────────┤
│ Layer 5: 服务网关层                          │
├─────────────────────────────────────────────┤
│ Layer 3: 插件运行时                          │
├─────────────────────────────────────────────┤
│ Layer 2: 核心功能插件组                      │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  │
│  │ Data IO  │  │ Logic    │  │ LLM +    │  │
│  │ 插件组    │  │ Fence    │  │ RAG      │  │
│  └──────────┘  └──────────┘  └──────────┘  │
├─────────────────────────────────────────────┤
│ Layer 1: 微内核 Core                         │
│  配置注册表 / 消息总线 / 日志 / 生命周期     │
└─────────────────────────────────────────────┘
```

### 设计原则
1. **依赖倒置**：所有插件仅依赖抽象接口，不依赖具体实现
2. **一切皆插件**：从通信协议到 AI 模型，所有功能可插拔
3. **渐进式增强**：从无依赖的规则模板开始，按需升级模型复杂度
4. **场景化按需加载**：超轻量嵌入式（~2MB）→ 边缘网关（~50MB）→ 云端集群（~200MB）

## 📦 功能模块说明

### RAG/Memory 时序语义桥接器

**核心接口：** `ITimeseriesSemanticBridge`

```python
# 1. 摄入时序数据并生成语义摘要
doc = await bridge.ingest_and_summarize(
    metric="reactor_temperature",
    points=timeseries_points,
    window_seconds=60,
)

# 2. 标注异常事件
anomaly_doc = await bridge.annotate_anomaly(
    metric="reactor_temperature",
    anomaly_point=anomaly,
    severity=AnomalySeverity.CRITICAL,
    context_window=history_points,
    description="冷却系统故障",
)

# 3. 构建 LLM 上下文
context = await bridge.build_context_prompt(
    metric="reactor_temperature",
    lookback_hours=1,
)
```
